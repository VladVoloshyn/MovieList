# MovieList

## Предметна область

MovieList — застосунок для ведення власного списку фільмів. Користувач може додавати фільми до колекції, переглядати інформацію про них та відмічати переглянуті фільми.

## Користувач

Користувачем застосунку є людина, яка хоче зберігати та впорядковувати список фільмів для перегляду.

## Основні сценарії

- додавання нового фільму до колекції;
- перегляд списку доданих фільмів;
- позначення фільму як переглянутого;
- отримання списку непроглянутих фільмів;
- додавання та перегляд нотаток до фільмів.

## Основні сутності

### Movie

Представляє окремий фільм та містить інформацію про його назву, рік випуску, жанр, статус перегляду та нотатку.

### MovieCollection

Представляє колекцію фільмів та забезпечує роботу зі списком: додавання фільмів, пошук, зміну статусу перегляду та отримання потрібних фільмів.

## Використані конструкції Swift

- `struct` — модель `Movie`.
- `class` — клас `MovieCollection`.
- `protocol` — протокол `Watchable`.
- `enum` — перелік `MovieGenre`.
- `let` і `var` — використовуються для констант і змінних властивостей.
- Колекція `[Movie]` — зберігає список фільмів.
- Optional `String?` — використовується для нотатки до фільму.
- Безпечне розгортання optional реалізовано через `if let`.
- Умовні конструкції реалізовано через `if/else`.
- Для роботи з колекцією використовуються `for`, `filter` та `first(where:)`.

## Перевірка сценарію

1. Відкрити проєкт `MovieList` у Xcode.
2. Обрати iPhone Simulator.
3. Запустити застосунок кнопкою Run.
4. Відкрити консоль Xcode.
5. У консолі буде продемонстровано створення та додавання фільмів, виведення списку, позначення фільму як переглянутого, фільтрацію непереглянутих фільмів та роботу з нотатками.
